## 4. RED FLAGS (Astra + подтверждения других судей)
1. **Все 5 seed-задач без `owner_contact`** → на стартовых данных нельзя показать решение бизнеса (§11), эксперт упирается в 403. Нужен seed с заявителями и коды входа в README.
2. **Guard не гарантирует «без выдумок»**: инверсия отрицания в `context`/`need` проходит; подсказки-кнопки обходили проверку (закрыто `9e6bee1`); шаблон вариантов результата попадает в карточку.
3. **Рейтинг накручивается**: 15/15 за неизмеримый критерий, 67 за бессмыслицу, дубль контекст=потребность (закрыто), «2 лет» как метрика (закрыто).
4. **Сценарий демо не соответствует продукту**, видео нет, показ ≤5 мин с речью не засечён — критерий «демонстрация» и §11 не доказаны.
5. **Приватность**: неопубликованные черновики доступны по id, `/api/ai` показывает чужой черновик, единый код 000000, сессии в памяти.
Дополнительно: fallback на mock при ошибке API теряет сведения из черновика (поле `data` пустое); «до/после» на главной — расчётная иллюстрация, а не сохранённые версии; отличие от Riipen/Parker Dewey не показано; в команде 2 человека при «3–5» в ТЗ.

## 5. UNPROVEN CLAIMS
- «Ничего не додумывает» — есть контрпример guard (отрицания) и шаблон вариантов.
- «Агент останавливается, когда сведений достаточно» — для OpenAI правило «данные, критерии, контакт» только в промпте; 2 из 3 прогонов закончились по лимиту 5 без критериев.
- «Ошибка API не нарушает сценарий» — повтор есть, полнота карточки при откате не доказана.
- «55→100 улучшило задачу» / «90–100 = готовность к работе» — внутренний балл, внешней оценки полезности нет.
- «Показ укладывается в 5 минут» — засечённого прогона с речью нет.
- Живой OpenAI — доказан только на стенде команды и в `docs/ai-live-sample.json`; жюри без ключа увидит mock.
