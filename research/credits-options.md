## Практические возможности для Education

- **Основной интеллектуальный контур:** OpenAI Responses API поддерживает function calling, поиск по файлам, web search, структурированные ответы и работу с текстом/изображениями. Возможный сценарий: принять учебный запрос → определить пробел в знаниях → найти релевантный фрагмент материала → составить персональное объяснение и упражнение → проверить ответ → адаптировать следующий шаг. Это гипотеза до получения ТЗ. [OpenAI tools](https://developers.openai.com/api/docs/guides/tools), [Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses).
- **Кредит Brev:** арендовать GPU-виртуальную машину, если понадобится локальный OCR, обработка видео/аудио, собственные embeddings/reranking или развёртывание NIM. На Brev есть готовые GPU-инстансы и Launchables; расход зависит от времени работы GPU и хранения. Это имеет смысл только при явной необходимости из ТЗ, поскольку демо должно воспроизводиться экспертами без личного аккаунта участника. [Brev GPU instances](https://docs.nvidia.com/brev/concepts/gpu-instances), [Brev Console Reference](https://docs.nvidia.com/brev/guides/console-reference).
- **ChatGPT & Codex Pro:** ускорить исследование, проектирование, код, ревью и проверку демо. Это инструмент разработки команды, а не оплаченный бэкенд продукта; эксперт должен запускать проект по README без нашего ChatGPT-аккаунта. [Раздельный биллинг](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).

## Ограничения и решение по бюджету

- Строить один законченный сценарий после публикации ТЗ; OpenAI API использовать там, где нужен агентный цикл, а не тратить кредит на массовые эксперименты до выбора продукта.
- Для OpenAI API выбрать модель по качеству/цене, ограничить длину ответов и число запросов, включить мониторинг расходов и при необходимости жёсткий лимит проекта. Встроенные инструменты могут иметь отдельную плату за вызов или хранение. [Цены OpenAI API](https://developers.openai.com/api/docs/pricing), [оптимизация стоимости](https://developers.openai.com/api/docs/guides/cost-optimization), [лимиты расходов](https://developers.openai.com/api/docs/guides/spend-limits).
- В Brev проверить цену выбранного GPU до запуска, не включать auto recharge без решения команды, останавливать/удалять неиспользуемые инстансы. Остановленный инстанс может продолжать расходовать баланс на хранение; при исчерпании кредита ресурсы могут быть удалены. Код и данные хранить в Git/устойчивом хранилище. [Brev Console Reference](https://docs.nvidia.com/brev/guides/console-reference).
- По Положению проект должен запускаться экспертами без личных аккаунтов команды. Значит, для внешнего API нужен тестовый доступ или mock-режим, документированный в README; не рассчитывать, что эксперты используют наши личные кредиты. См. `HACKATHON_RULES.md`, п. 5.6.6.
