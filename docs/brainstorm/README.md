# AI Sana: карта для обсуждения Ильяса и Абылая

Откройте [`ai-sana-product-map.excalidraw.md`](./ai-sana-product-map.excalidraw.md) в Obsidian с плагином Excalidraw. Это снимок карты из Obsidian Ильяса на 23.09.2026, переданный Абылаю для совместного обсуждения. Файл можно скопировать в свой vault и открыть в Excalidraw View.

На карте есть модули продукта, полный путь бизнеса и студенческой команды, мобильные и сложные сценарии, вопросы для совместных решений и отдельный раздел «ТЗ простыми словами» с формулой рейтинга и рубрикой жюри. Раздел «Чат как основной вход» — гипотеза Ильяса: бизнес описывает проблему в разговоре, AI уточняет пробелы и одновременно собирает видимую редактируемую карточку. Дополнение «Контекст бизнеса» описывает необязательные запросы сайта, соцсетей, PDF/DOC и других файлов через артефакты, проверку извлечённых фактов, ритм вопросов и отдельные user flow / context flow. Это концепция для обсуждения и проверки с людьми, не утверждённая смена MVP.

**Граница источников:** официальный текст задания — [`TASK.md`](../../TASK.md). Блок «ТЗ простыми словами» — пересказ, а путь пользователя, варианты голосового ввода, импорта контекста и работа после выбора команды — продуктовые гипотезы для обсуждения. Текущие решения и состояние MVP определяются [`STATUS.md`](../../STATUS.md), [`PLAN.md`](../../PLAN.md) и [`API_CONTRACT.md`](../../API_CONTRACT.md), а не этой картой.

В этом снимке нет клиентских переписок, записей звонков, базы лидов или персональных контактов.
