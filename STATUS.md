## Что строим

Официальный кейс Education — **AI Sana Challenge Hub: от бизнес-задачи к решению**. Полное ТЗ и рубрика опубликованы в `TASK.md` (`ec2690d`). Утверждён продуктовый сценарий A: сырой запрос бизнеса → минимум 3 AI-вопроса → редактируемая и подтверждённая карточка → прозрачный рейтинг 0–100 → открытый каталог → свободный отклик команды → ручной выбор бизнеса. Окончательный стек: Go JSON API + PostgreSQL + Vite/React/TypeScript. `PLAN.md` задаёт объём MVP, `API_CONTRACT.md` — интерфейс и формат seed. Технический сквозной сценарий пройден; дальше приёмка демо, seed и UX.
